# kush-gupt.github.io

My personal site, styled as a terminal. Type `help` to see what it can do.

## Run locally

```bash
python3 -m http.server 8000
# open http://localhost:8000
```

## Files

- `index.html` — terminal window shell
- `styles.css` — CRT/phosphor styling
- `terminal.js` — boot sequence, command interpreter, themes

## Commands

`help` `whoami` `experience` `education` `certs` `projects` `stack`
`personal` `contact` `theme` `clear`
