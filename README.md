# kush-gupt.github.io — terminal rebuild

A terminal-themed personal site for Kush Gupta, built from scratch on the
`terminal-rebuild` branch.

## Run locally

```bash
python3 -m http.server 8000
# open http://localhost:8000
```

## Files

- `index.html` — terminal window shell
- `styles.css` — CRT/phosphor styling
- `terminal.js` — boot sequence, command interpreter, themes

## Commands

`help` `whoami` `experience` `education` `certs` `projects` `stack`
`personal` `contact` `theme` `clear`
